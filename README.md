# IT-Support-Troubleshooting-Guide
A beginner-friendly guide documenting common IT support and networking troubleshooting scenarios.

## Troubleshooting Process
When troubleshooting an IT issue, I follow these steps:
1. Identify the problem
2. Gather information
3. Check possible causes
4. Test possible solutions
5. Apply the appropriate sloution
6. Verfiy that the issue is resolved
7. Document the solution
   
## Case 01: No Internet Connection
### Problem
the computer is connected to the network, but the user cannot access the Internt.
### Possible Causes
- Wi-Fi or Ethernet connection is disconnected
- Incorrect IP configuration
- DNS issue
- Router or network problem

### Troubleshooting Steps
1. Check the Wi-Fi or Ethernet connection.
2. Open Command Prompt.
3. Run 'ipconfig'.
4. check the IPv4 Address and Default Gateway.
5. run 'ping 8.8.8.8'.
6. Check whether the computer can reach the Internet.
7. Document the results and resolution

### Tools Used
- Command prompt
- 'ipconfig'
-  'ping'
